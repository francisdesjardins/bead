Bead DevTools et vos données

L’extension montre ce que font les clients Bead d’une page. Elle n’envoie rien nulle part.

En bref

Bead DevTools est une extension de Chrome qui ajoute un panneau Bead aux DevTools. Le panneau montre les appels, les enveloppes, les métriques et les colis du courtier des clients Bead que construit la page que vous inspectez.

  • Elle ne lit que ce que les clients Bead d’une page disent à son crochet, et les échanges HTTP propres à Bead.
  • Elle garde ce qu’elle lit dans la mémoire du panneau, jusqu’à ce qu’il se ferme ou que vous le vidiez.
  • Elle n’envoie rien hors de votre navigateur. Elle n’a ni serveur, ni mesure d’audience, ni publicité, et n’exécute aucun code qui ne soit dans son paquet.
  • Elle ne demande aucune permission à Chrome. Elle ne vend ni ne partage aucune donnée.

Ce qu’elle lit

Sur chaque page, avant que ses propres scripts ne s’exécutent, l’extension définit un crochet. Un client Bead construit dans cette page s’annonce à ce crochet. Tant qu’aucun panneau Bead n’est ouvert sur l’onglet, le crochet ne transmet rien d’autre que l’annonce d’un client et son genre.

Pendant qu’un panneau Bead est ouvert sur l’onglet, le crochet et le panneau lisent :

  • chaque appel que font ou que servent les clients Bead de la page : sa procédure, ses temps, son statut, et ses charges utiles en texte et en arbre ;
  • chaque enveloppe que ces clients envoient et reçoivent, et les métriques de chacun ;
  • les colis, les changements de lien et les rapports de chaque participant de courtier Bead que la page construit ;
  • la pile du code qui a fait chaque appel, les adresses et les lignes de ses scripts, pour que le panneau puisse l’ouvrir dans Sources ;
  • dans le panneau Network, seulement les échanges dont le type de contenu est celui de Bead, application/prs.bead, et leurs corps. Il ignore tout autre échange.

Un justificatif que porte un appel n’est noté que par son schéma, jamais par son jeton. Une page ou une application peut tenir ses clients à l’écart du panneau en leur donnant devtools: false.

Ce qu’elle garde

Ce que lit le panneau reste dans sa mémoire. Il disparaît quand le panneau se ferme, quand les DevTools se ferment, ou quand vous le videz. Avec Preserve log, il reste d’un rechargement de la page à l’autre, tant que les DevTools restent ouverts. L’extension n’en écrit rien sur votre disque.

Le panneau garde deux de vos choix dans le stockage propre à l’extension, sur votre appareil : où il place le détail d’un appel, et la part de la séparation entre la liste et le détail. Il n’y garde rien d’autre.

Trois actions écrivent ou lisent un fichier, chacune seulement à votre demande :

  • Export enregistre les enregistrements que tient le panneau dans un fichier JSON, là où votre navigateur enregistre les fichiers.
  • Import lit un fichier JSON que vous choisissez, dans le panneau seul.
  • Le menu d’un appel copie sa requête, sa réponse ou un extrait de code dans votre presse-papiers.

Ce qu’elle envoie

Rien ne quitte votre navigateur. L’extension ne fait aucune requête réseau à elle. Elle n’a ni mesure d’audience, ni télémétrie, ni rapport de plantage, ni compte. Tout son code est dans le paquet que distribue le Chrome Web Store, et elle ne charge aucun code distant.

Les enregistrements ne voyagent que dans le navigateur : du crochet, dans la page, au pont de l’extension, puis à son service worker, puis au panneau du même onglet, par la messagerie de Chrome.

L’extension ne change rien à la page que le crochet qu’elle définit. Elle ne recharge la page que si vous le lui demandez.

Ses permissions

Le manifeste de l’extension ne nomme aucune permission et aucune permission d’hôte. Il déclare quatre parties :

  • deux scripts de contenu sur toute adresse, <all_urls>, à document_start : le crochet, dans le monde propre de la page, qui doit être en place avant que le client Bead de la page ne se charge ; et le pont, dans le monde isolé de l’extension, qui porte les enregistrements du crochet jusqu’au panneau ;
  • une page DevTools, qui ajoute le panneau Bead aux DevTools ;
  • un service worker, qui associe chaque onglet au panneau ouvert sur lui.

Chrome prévient que de tels scripts de contenu peuvent lire et modifier vos données sur tous les sites. Le crochet ne lit que ce que lui donnent les clients Bead d’une page, et le garde dans votre navigateur.
